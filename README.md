# Serverless GPU migration example (MLB object detection)

An example of moving Databricks Serverless GPU training from the deprecated `serverless_gpu`
package to the Databricks AI Runtime (the `databricks air` CLI and the `ai_runtime_task` in
Declarative Automation Bundles), using a YOLOv8 ball/bat/glove detector as the workload.

See the feature branch / PR for the demo code.
